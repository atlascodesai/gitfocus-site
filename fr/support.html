Questions fréquemment posées

Non ! GitFocus n'a besoin que du ou des noms d'utilisateur GitHub que tu choisis de suivre. Nous lisons les graphiques de contributions publiques (les carrés verts sur les profils) pour détecter les commits. Aucun OAuth, aucun jeton, aucun mot de passe requis.

Tu peux ajouter plusieurs comptes GitHub et décider lesquels comptent pour la détection de commits.

GitFocus utilise l'API Temps d'écran d'Apple pour bloquer les applications. C'est le même système sécurisé qui alimente les contrôles parentaux intégrés d'Apple. Nous avons besoin d'une autorisation pour appliquer des restrictions d'application en ton nom.

Oui ! GitHub compte tous les commits (publics et privés) dans ton graphique de contributions par défaut. Tant que tes paramètres de contribution sont configurés pour afficher "Contributions privées", nous les verrons.

Va sur ton profil GitHub → Paramètres de contribution → Coche "Contributions privées"

Chaque commit te rapporte 5 minutes de temps de déverrouillage. Pusher 3 commits ? C'est 15 minutes pour scroller Twitter sans culpabilité. 🎉

Les vies sont des déverrouillages d'urgence. Lorsque tu utilises une vie, toutes tes applications bloquées sont déverrouillées jusqu'à minuit. Tu commences avec 1 vie gratuite et peux en gagner davantage grâce aux séries :

  • Série de 14 jours : +1 vie
  • Puis +1 vie chaque mois où tu maintiens la série

Besoin de terminer un message rapide mais tu n'as pas de temps de déverrouillage ? Tu peux emprunter jusqu'à 5 minutes. Cela crée une "dette" qui sera remboursée à partir de tes futurs gains de commits.

Exemple : Tu empruntes 3 minutes. Ton prochain commit rapporte 5 minutes, mais 3 servent à rembourser la dette, te laissant 2 minutes.

La Banque de discipline suit le temps que tu as gagné mais que tu n'as pas utilisé. C'est une mesure de ta maîtrise de soi. Chaque minute que tu gagnes mais que tu ne dépenses pas en distractions va dans ta banque.

Lance-toi un défi : Combien de minutes peux-tu mettre en banque d'ici la fin de l'année ?

Construire une série déverrouille des avantages permanents :

  • 14 jours : +1 vie supplémentaire (puis +1/mois)
  • 30 jours : Banque de temps hebdomadaire (le temps non utilisé se réinitialise chaque semaine au lieu de chaque jour)
  • 90 jours : Temps permanent (le temps gagné n'expire jamais)

Voici quelques points à vérifier :

  • Assure-toi que ton nom d'utilisateur GitHub est entré correctement
  • Si tu utilises plusieurs comptes, vérifie que les bons comptes sont activés pour la détection de commits
  • Vérifie que tes commits apparaissent sur le graphique de contributions de ton profil GitHub
  • Si tu utilises des dépôts privés, assure-toi que "Contributions privées" est activé dans les paramètres GitHub
  • Attends quelques minutes — le graphique de contributions de GitHub peut prendre du temps à se mettre à jour

Assure-toi d'avoir :

  • Accordé les autorisations Temps d'écran lors de la configuration
  • Sélectionné au moins une application ou catégorie à bloquer
  • Démarré une session de concentration depuis l'écran principal

Si les problèmes persistent, essaie d'aller dans Réglages iOS → Temps d'écran et assure-toi que GitFocus dispose des autorisations nécessaires.

Essaie ces étapes :

  • Force la fermeture et rouvre l'application
  • Redémarre ton appareil
  • Assure-toi d'avoir la dernière version de GitFocus
  • Si le problème persiste, envoie-nous un e-mail à support@gitfocus.app avec des détails sur ce qui s'est passé

Pour réinitialiser complètement GitFocus :

  • Supprime l'application de ton appareil
  • Réinstalle depuis l'App Store
  • Passe à nouveau par l'intégration

Remarque : Ton nom d'utilisateur GitHub ou ta liste de comptes est stocké de manière sécurisée pour plus de commodité, donc il peut être pré-rempli lorsque tu réinstalles.
