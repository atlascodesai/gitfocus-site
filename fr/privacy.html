// Politique de confidentialité

Tes données restent les tiennes

Nous avons conçu GitFocus avec la confidentialité comme principe fondamental. Voici exactement ce que nous faisons (et ne faisons pas) avec tes informations.

Dernière mise à jour : janvier 2026

// En bref

Nous ne collectons pas tes données. Point final.

Aucun compte requis
Tout sur l'appareil
Aucun suivi ni analytique
Fonctionne hors ligne

Données que nous collectons

Aucune. GitFocus ne collecte, ne stocke ni ne transmet aucune donnée personnelle à nos serveurs, car nous n'avons aucun serveur vers lequel les envoyer.

Tout ce dont l'application a besoin pour fonctionner est stocké localement sur ton appareil :

  • Ton nom d'utilisateur GitHub ou tes noms d'utilisateur (pour vérifier les commits publics)
  • Tes préférences de sélection d'applications
  • Ton historique de sessions de concentration
  • Ton temps gagné et tes données de séries

Intégration GitHub

GitFocus lit les données de contribution GitHub publiques pour le ou les noms d'utilisateur que tu ajoutes afin de déterminer quand tu as effectué des commits. Voici comment cela fonctionne :

Ce à quoi nous accédons

  • Ta page de profil GitHub publique
  • Ton graphique de contributions publiques (les carrés verts)
  • Le nombre de commits par jour (pas le contenu des commits)

Ce à quoi nous n'accédons pas

  • Dépôts privés
  • Messages de commit ou code
  • Ton mot de passe GitHub ou tes jetons
  • Aucune API GitHub avec authentification

Aucun OAuth requis

Nous avons intentionnellement conçu GitFocus pour fonctionner sans authentification GitHub. Tu peux ajouter un ou plusieurs noms d'utilisateur GitHub, et nous ne lisons que les informations accessibles publiquement que n'importe qui peut voir en visitant ces profils GitHub.

Temps d'écran et blocage d'applications

GitFocus utilise l'API Screen Time d'Apple (framework Family Controls) pour bloquer les applications. C'est le même système sécurisé qui alimente les fonctionnalités Temps d'écran intégrées d'Apple.

Comment ça fonctionne

  • Le blocage des applications est entièrement géré par iOS, pas notre code
  • Nous ne voyons jamais quelles applications tu utilises ni pendant combien de temps
  • Les protections de confidentialité d'Apple s'appliquent à toutes les données Temps d'écran
  • Nous ne recevons que des "jetons" anonymisés qui représentent les applications

Ce que nous ne pouvons pas voir

  • Tes statistiques d'utilisation des applications
  • Quand tu ouvres ou fermes des applications
  • Combien de temps tu passes dans une application
  • Les noms réels des applications que tu sélectionnes (uniquement des jetons)

Stockage local des données

Toutes tes données sont stockées sur ton appareil en utilisant les mécanismes de stockage sécurisés d'Apple :

  • UserDefaults — Paramètres et préférences
  • Keychain — Ton nom d'utilisateur GitHub principal (pour la persistance entre les réinstallations)
  • App Group — Données partagées entre l'application et les extensions

Ces données sont chiffrées par iOS et protégées par le code de ton appareil. Si tu supprimes l'application, tes données locales sont également supprimées.

Services tiers

GitFocus n'utilise aucun service tiers d'analytique, de rapports de crash ou de publicité. Nous ne nous intégrons pas avec :

  • Google Analytics
  • Firebase
  • Crashlytics
  • Facebook SDK
  • Réseaux publicitaires
  • Services de suivi des utilisateurs

Les seuls services externes avec lesquels nous communiquons sont github.com pour récupérer tes données de contribution publiques, et notre chat de support client optionnel (voir ci-dessous).

Support client et chat en direct

Contacter le support est entièrement optionnel et n'a lieu que lorsque tu choisis de nous contacter pour obtenir de l'aide.

GitFocus offre un support client via chat en direct propulsé par Chatwoot, une plateforme de support client tierce. C'est le seul service tiers utilisé par GitFocus (en plus de GitHub), et il n'est actif que lorsque tu choisis explicitement de nous contacter pour obtenir de l'aide.

Comment ça fonctionne

  • Persistance de session : Chatwoot utilise des cookies pour maintenir ta session de chat entre les visites, afin que tu puisses continuer les conversations précédentes
  • Anonyme par défaut : Tu peux chatter avec le support sans fournir d'informations personnelles - la session est suivie uniquement via les cookies du navigateur
  • Email optionnel : Tu peux éventuellement fournir ton adresse e-mail si tu souhaites recevoir des réponses de suivi

Ce qui est collecté

Lorsque tu utilises la fonctionnalité de chat, Chatwoot peut collecter :

  • Tes messages de chat et l'historique des conversations
  • Les cookies du navigateur pour la persistance de session
  • Adresse e-mail (uniquement si tu choisis de la fournir)
  • Informations techniques de base (type de navigateur, horodatage)

Aucun accès aux données de l'application

La fonctionnalité de chat n'a PAS accès à tes données GitHub, à l'historique de tes sessions de concentration ou à toute autre donnée stockée dans l'application GitFocus. Seules les informations que tu tapes explicitement dans le chat sont envoyées à notre système de support.

Chatwoot est conforme au RGPD et traite les données conformément aux lois applicables en matière de protection des données. Pour plus d'informations, consultez chatwoot.com/privacy-policy.

Tu peux effacer les cookies du chat à tout moment via les paramètres de ton navigateur. Si tu n'utilises jamais la fonctionnalité de chat, aucune donnée n'est jamais envoyée à Chatwoot.

Tes droits

Puisque nous ne collectons pas tes données, les droits traditionnels sur les données (accès, suppression, portabilité) ne s'appliquent pas vraiment. Mais voici ce que tu peux faire :

  • Supprimer toutes les données — Supprime simplement l'application de ton appareil
  • Exporter les données — Tes données se trouvent sur ton appareil ; elles t'appartiennent
  • Modifier les paramètres — Toutes les préférences peuvent être modifiées dans l'application

Confidentialité des enfants et classification par âge

GitFocus est classé 4+ sur l'App Store et convient aux utilisateurs de tous âges. L'application ne contient aucun contenu répréhensible, achat intégré ou fonctionnalité sociale.

Puisque nous ne collectons aucune donnée personnelle, il n'y a aucune préoccupation particulière en matière de confidentialité pour les jeunes utilisateurs. Cependant, nous recommandons que les enfants de moins de 13 ans configurent l'application avec l'accompagnement parental, car :

  • La configuration initiale nécessite un nom d'utilisateur GitHub
  • Les autorisations Temps d'écran doivent être accordées par le propriétaire de l'appareil
  • Comprendre le système de déverrouillage basé sur les commits peut nécessiter des explications

Les parents et tuteurs peuvent utiliser GitFocus comme outil pour encourager les habitudes de codage chez les jeunes développeurs.

Modifications de cette politique

Si nous modifions un jour nos pratiques de confidentialité, nous mettrons à jour cette page avec une nouvelle date "Dernière mise à jour". Compte tenu de notre approche de non-collecte de données, des changements significatifs sont peu probables.
