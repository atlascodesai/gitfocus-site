Δεδομένα που Συλλέγουμε

Κανένα. Το GitFocus δεν συλλέγει, αποθηκεύει ή μεταδίδει προσωπικά δεδομένα στους διακομιστές μας επειδή δεν έχουμε διακομιστές για να τα στείλουμε.

Όλα όσα χρειάζεται η εφαρμογή για να λειτουργήσει αποθηκεύονται τοπικά στη συσκευή σας:

  • Το όνομα χρήστη ή τα ονόματα χρήστη GitHub (για έλεγχο δημόσιων commits)
  • Οι προτιμήσεις επιλογής εφαρμογών σας
  • Το ιστορικό συνεδριών εστίασής σας
  • Τα δεδομένα κερδισμένου χρόνου και σειράς σας

Ενσωμάτωση GitHub

Το GitFocus διαβάζει δημόσια δεδομένα συνεισφορών GitHub για το όνομα ή τα ονόματα χρήστη που προσθέτετε, για να προσδιορίσει πότε έχετε κάνει commits. Δείτε πώς λειτουργεί:

Τι Έχουμε Πρόσβαση

  • Τη δημόσια σελίδα προφίλ GitHub σας
  • Το δημόσιο γράφημα συνεισφορών σας (τα πράσινα τετράγωνα)
  • Μετρήσεις commits ανά ημέρα (όχι το περιεχόμενο των commits)

Τι Δεν Έχουμε Πρόσβαση

  • Ιδιωτικά αποθετήρια
  • Μηνύματα commit ή κώδικα
  • Τον κωδικό πρόσβασης ή τα tokens GitHub σας
  • Οποιοδήποτε GitHub API με έλεγχο ταυτότητας

Δεν Απαιτείται OAuth

Σχεδιάσαμε σκόπιμα το GitFocus να λειτουργεί χωρίς έλεγχο ταυτότητας GitHub. Μπορείτε να προσθέσετε ένα ή περισσότερα ονόματα χρήστη GitHub, και διαβάζουμε μόνο δημόσια διαθέσιμες πληροφορίες που μπορεί να δει οποιοσδήποτε επισκεπτόμενος αυτά τα προφίλ GitHub.

Χρόνος Οθόνης & Αποκλεισμός Εφαρμογών

Το GitFocus χρησιμοποιεί το Screen Time API της Apple (πλαίσιο Family Controls) για τον αποκλεισμό εφαρμογών. Είναι το ίδιο ασφαλές σύστημα που τροφοδοτεί τις ενσωματωμένες λειτουργίες Screen Time της Apple.

Πώς Λειτουργεί

  • Ο αποκλεισμός εφαρμογών διαχειρίζεται εξ ολοκλήρου από το iOS, όχι από τον κώδικά μας
  • Δεν βλέπουμε ποτέ ποιες εφαρμογές χρησιμοποιείτε ή για πόσο χρόνο
  • Οι προστασίες απορρήτου της Apple ισχύουν για όλα τα δεδομένα Screen Time
  • Λαμβάνουμε μόνο ανώνυμα "tokens" που αντιπροσωπεύουν εφαρμογές

Τι Δεν Μπορούμε να Δούμε

  • Τα στατιστικά χρήσης εφαρμογών σας
  • Πότε ανοίγετε ή κλείνετε εφαρμογές
  • Πόσο χρόνο περνάτε σε κάθε εφαρμογή
  • Τα πραγματικά ονόματα των εφαρμογών που επιλέγετε (μόνο tokens)

Τοπική Αποθήκευση Δεδομένων

Όλα τα δεδομένα σας αποθηκεύονται στη συσκευή σας χρησιμοποιώντας τους ασφαλείς μηχανισμούς αποθήκευσης της Apple:

  • UserDefaults — Ρυθμίσεις και προτιμήσεις
  • Keychain — Το κύριο όνομα χρήστη GitHub σας (για διατήρηση μεταξύ επανεγκαταστάσεων)
  • App Group — Κοινά δεδομένα μεταξύ εφαρμογής και επεκτάσεων

Αυτά τα δεδομένα κρυπτογραφούνται από το iOS και προστατεύονται από τον κωδικό πρόσβασης της συσκευής σας. Εάν διαγράψετε την εφαρμογή, τα τοπικά σας δεδομένα διαγράφονται επίσης.

Υπηρεσίες Τρίτων

Το GitFocus δεν χρησιμοποιεί υπηρεσίες αναλυτικών, αναφοράς σφαλμάτων ή διαφήμισης τρίτων. Δεν ενσωματώνουμε:

  • Google Analytics
  • Firebase
  • Crashlytics
  • Facebook SDK
  • Οποιοδήποτε διαφημιστικό δίκτυο
  • Οποιαδήποτε υπηρεσία παρακολούθησης χρηστών

Οι μόνες εξωτερικές υπηρεσίες με τις οποίες επικοινωνούμε είναι το github.com για να λάβουμε τα δημόσια δεδομένα συνεισφορών σας, και η προαιρετική συνομιλία υποστήριξης πελατών μας (δείτε παρακάτω).

Υποστήριξη Πελατών & Ζωντανή Συνομιλία

Η επικοινωνία με την υποστήριξη είναι εντελώς προαιρετική και συμβαίνει μόνο όταν επιλέγετε να επικοινωνήσετε για βοήθεια.

Το GitFocus προσφέρει υποστήριξη πελατών μέσω ζωντανής συνομιλίας που παρέχεται από το Chatwoot, μια πλατφόρμα υποστήριξης πελατών τρίτων. Αυτή είναι η μόνη υπηρεσία τρίτων που χρησιμοποιείται από το GitFocus (εκτός από το GitHub), και είναι ενεργή μόνο όταν επιλέγετε ρητά να επικοινωνήσετε μαζί μας για βοήθεια.

Πώς λειτουργεί

  • Διατήρηση συνεδρίας: Το Chatwoot χρησιμοποιεί cookies για να διατηρήσει τη συνεδρία συνομιλίας σας μεταξύ επισκέψεων, ώστε να μπορείτε να συνεχίσετε προηγούμενες συνομιλίες
  • Ανώνυμο από προεπιλογή: Μπορείτε να συνομιλήσετε με την υποστήριξη χωρίς να παρέχετε προσωπικές πληροφορίες - η συνεδρία παρακολουθείται μόνο μέσω cookies του προγράμματος περιήγησης
  • Προαιρετικό email: Μπορείτε προαιρετικά να δώσετε τη διεύθυνση email σας εάν θέλετε να λαμβάνετε απαντήσεις παρακολούθησης

Τι Συλλέγεται

Όταν χρησιμοποιείτε τη λειτουργία συνομιλίας, το Chatwoot μπορεί να συλλέξει:

  • Τα μηνύματα συνομιλίας και το ιστορικό συνομιλιών σας
  • Cookies προγράμματος περιήγησης για διατήρηση συνεδρίας
  • Διεύθυνση email (μόνο εάν επιλέξετε να την παρέχετε)
  • Βασικές τεχνικές πληροφορίες (τύπος προγράμματος περιήγησης, χρονοσήμανση)

Δεν Υπάρχει Πρόσβαση στα Δεδομένα της Εφαρμογής

Η λειτουργία συνομιλίας ΔΕΝ έχει πρόσβαση στα δεδομένα GitHub σας, το ιστορικό συνεδριών εστίασης ή οποιαδήποτε άλλα δεδομένα αποθηκευμένα στην εφαρμογή GitFocus. Μόνο οι πληροφορίες που πληκτρολογείτε ρητά στη συνομιλία αποστέλλονται στο σύστημα υποστήριξής μας.

Το Chatwoot συμμορφώνεται με το GDPR και επεξεργάζεται δεδομένα σύμφωνα με τους ισχύοντες νόμους προστασίας δεδομένων. Για περισσότερες πληροφορίες, επισκεφτείτε chatwoot.com/privacy-policy.

Μπορείτε να διαγράψετε τα cookies συνομιλίας ανά πάσα στιγμή μέσω των ρυθμίσεων του προγράμματος περιήγησής σας. Εάν δεν χρησιμοποιήσετε ποτέ τη λειτουργία συνομιλίας, δεν αποστέλλονται ποτέ δεδομένα στο Chatwoot.

Τα Δικαιώματά Σας

Εφόσον δεν συλλέγουμε τα δεδομένα σας, τα παραδοσιακά δικαιώματα δεδομένων (πρόσβαση, διαγραφή, φορητότητα) δεν ισχύουν πραγματικά. Αλλά εδώ είναι τι μπορείτε να κάνετε:

  • Διαγραφή όλων των δεδομένων — Απλά διαγράψτε την εφαρμογή από τη συσκευή σας
  • Εξαγωγή δεδομένων — Τα δεδομένα σας βρίσκονται στη συσκευή σας· είναι δικά σας
  • Αλλαγή ρυθμίσεων — Όλες οι προτιμήσεις μπορούν να τροποποιηθούν στην εφαρμογή

Απόρρητο Παιδιών & Βαθμολογία Ηλικίας

Το GitFocus έχει βαθμολογία 4+ στο App Store και είναι κατάλληλο για χρήστες όλων των ηλικιών. Η εφαρμογή δεν περιέχει ανάρμοστο περιεχόμενο, αγορές εντός εφαρμογής ή κοινωνικές λειτουργίες.

Εφόσον δεν συλλέγουμε προσωπικά δεδομένα, δεν υπάρχουν ειδικές ανησυχίες απορρήτου για νεότερους χρήστες. Ωστόσο, συνιστούμε τα παιδιά κάτω των 13 ετών να ρυθμίσουν την εφαρμογή με γονική καθοδήγηση, καθώς:

  • Η αρχική ρύθμιση απαιτεί όνομα χρήστη GitHub
  • Οι άδειες Screen Time πρέπει να χορηγηθούν από τον κάτοχο της συσκευής
  • Η κατανόηση του συστήματος ξεκλειδώματος βάσει commits μπορεί να χρειάζεται επεξήγηση

Οι γονείς και κηδεμόνες μπορούν να χρησιμοποιήσουν το GitFocus ως εργαλείο για να ενθαρρύνουν συνήθειες προγραμματισμού σε νέους προγραμματιστές.
