// 隐私政策

您的数据归您所有

我们在构建 GitFocus 时将隐私作为核心原则。以下是我们如何处理（以及不处理）您的信息的详细说明。

最后更新：2026年1月

// 简而言之

我们不收集您的数据。就这么简单。

无需账户
一切都在设备本地
无追踪或分析
离线可用

我们收集的数据

无。 GitFocus 不收集、存储或向我们的服务器传输任何个人数据，因为我们根本没有服务器。

应用程序运行所需的所有内容都存储在您的设备本地：

  • 您的 GitHub 用户名（用于检查公开提交）
  • 您的应用程序选择偏好
  • 您的专注会话历史
  • 您获得的时间和连续记录数据

GitHub 集成

GitFocus 读取您添加的用户名的公开 GitHub 贡献数据，以确定您何时进行了提交。其工作原理如下：

我们访问的内容

  • 您的公开 GitHub 个人资料页面
  • 您的公开贡献图（绿色方块）
  • 每日提交次数（而非提交内容）

我们不访问的内容

  • 私有仓库
  • 提交消息或代码
  • 您的 GitHub 密码或令牌
  • 任何需要身份验证的 GitHub API

无需 OAuth

我们特意将 GitFocus 设计为无需 GitHub 身份验证即可工作。您可以添加一个或多个 GitHub 用户名，我们只读取任何人访问这些 GitHub 个人资料时都能看到的公开信息。

屏幕使用时间与应用程序屏蔽

GitFocus 使用 Apple 的 Screen Time API（Family Controls 框架）来屏蔽应用程序。这与为 Apple 内置屏幕使用时间功能提供支持的安全系统相同。

工作原理

  • 应用程序屏蔽完全由 iOS 处理，而非我们的代码
  • 我们永远不会看到您使用了哪些应用程序或使用时长
  • Apple 的隐私保护适用于所有屏幕使用时间数据
  • 我们只接收代表应用程序的匿名"令牌"

我们看不到的内容

  • 您的应用程序使用统计
  • 您何时打开或关闭应用程序
  • 您在任何应用程序中花费的时间
  • 您选择的应用程序的实际名称（仅有令牌）

本地数据存储

您的所有数据都使用 Apple 的安全存储机制存储在您的设备上：

  • UserDefaults — 设置和偏好
  • Keychain — 您的主要 GitHub 用户名（用于在重新安装时保持）
  • App Group — 应用程序和扩展之间共享的数据

这些数据由 iOS 加密并受您的设备密码保护。如果您删除应用程序，您的本地数据也会被删除。

第三方服务

GitFocus 不使用任何第三方分析、崩溃报告或广告服务。我们不集成：

  • Google Analytics
  • Firebase
  • Crashlytics
  • Facebook SDK
  • 任何广告网络
  • 任何用户追踪服务

我们唯一通信的外部服务是 github.com（用于获取您的公开贡献数据）和我们的可选客户支持聊天（见下文）。

客户支持与在线聊天

联系支持完全是可选的，仅在您选择寻求帮助时才会发生。

GitFocus 通过由第三方客户支持平台 Chatwoot 提供支持的在线聊天提供客户支持。这是 GitFocus 使用的唯一第三方服务（除 GitHub 外），并且仅在您明确选择联系我们寻求帮助时才会激活。

工作原理

  • 会话持久性： Chatwoot 使用 cookie 在访问之间维护您的聊天会话，以便您可以继续之前的对话
  • 默认匿名： 您可以在不提供任何个人信息的情况下与支持聊天 - 会话仅通过浏览器 cookie 进行跟踪
  • 可选电子邮件： 如果您希望接收后续回复，可以选择提供您的电子邮件地址

收集的内容

当您使用聊天功能时，Chatwoot 可能会收集：

  • 您的聊天消息和对话历史
  • 用于会话持久性的浏览器 cookie
  • 电子邮件地址（仅当您选择提供时）
  • 基本技术信息（浏览器类型、时间戳）

无法访问应用程序数据

聊天功能无法访问您的 GitHub 数据、专注会话历史或存储在 GitFocus 应用程序中的任何其他数据。只有您在聊天中明确输入的信息才会发送到我们的支持系统。

Chatwoot 符合 GDPR 并根据适用的数据保护法律处理数据。欲了解更多信息，请访问 chatwoot.com/privacy-policy.

您可以随时通过浏览器设置清除聊天 cookie。如果您从未使用过聊天功能，则不会向 Chatwoot 发送任何数据。

您的权利

由于我们不收集您的数据，传统的数据权利（访问、删除、可移植性）并不真正适用。但您可以做到以下几点：

  • 删除所有数据 — 只需从您的设备中删除应用程序
  • 导出数据 — 您的数据存储在您的设备上；您拥有它
  • 更改设置 — 所有偏好都可以在应用程序中修改

儿童隐私与年龄分级

GitFocus 的评级为 4+ 在 App Store 上，适合所有年龄段的用户。该应用程序不包含不良内容、应用内购买或社交功能。

由于我们不收集任何个人数据，因此对年轻用户没有特殊的隐私顾虑。但是，我们建议13岁以下的儿童在父母指导下设置应用程序，因为：

  • 初始设置需要 GitHub 用户名
  • 屏幕使用时间权限需要由设备所有者授予
  • 理解基于提交的解锁系统可能需要解释

家长和监护人可以使用 GitFocus 作为鼓励年轻开发者养成编码习惯的工具。

本政策的变更

如果我们改变隐私做法，我们将更新此页面并标注新的"最后更新"日期。鉴于我们不收集数据的方法，重大变更不太可能发生。
