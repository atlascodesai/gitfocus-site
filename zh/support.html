每次提交为您赚取 5分钟 的解锁时间。推送3次提交？那就是15分钟无负罪感地浏览 Twitter。🎉

生命是紧急解锁。当您使用一次生命时，您所有被屏蔽的应用程序都会解锁直到午夜。您从1次免费生命开始，并可以通过连续记录获得更多：

  • 14天连续：+1次生命
  • 然后每维持连续一个月获得+1次生命

需要完成一条快速消息但没有解锁时间？您可以借用最多5分钟。这会产生"债务"，从您未来的提交收益中偿还。

示例：您借用3分钟。您的下一次提交赚取5分钟，但3分钟用于偿还债务，剩下2分钟。

自律银行追踪您赚取但未使用的时间。这是您自我控制能力的衡量标准。您赚取但未花费在分心事物上的每一分钟都会存入您的银行。

挑战自己：到年底您能存入多少分钟？

建立连续记录可解锁永久奖励：

  • 14天： +1次额外生命（然后每月+1次）
  • 30天： 每周时间银行（未使用的时间每周重置而非每日）
  • 90天： 永久时间（赚取的时间永不过期）

以下是需要检查的一些事项：

  • 确保您的 GitHub 用户名输入正确
  • 如果您使用多个账户，请检查是否为提交检测启用了正确的账户
  • 检查您的提交是否显示在您的 GitHub 个人资料的贡献图上
  • 如果使用私有仓库，请确保在 GitHub 设置中启用了"私有贡献"
  • 等待几分钟 — GitHub 的贡献图可能需要一些时间更新

请确保您已：

  • 在设置期间授予了屏幕使用时间权限
  • 选择了至少一个要屏蔽的应用程序或类别
  • 从主屏幕开始了专注会话

如果问题仍然存在，请尝试前往 iOS 设置 → 屏幕使用时间，并确保 GitFocus 具有必要的权限。

尝试以下步骤：

  • 强制退出并重新打开应用程序
  • 重启您的设备
  • 确保您使用的是最新版本的 GitFocus
  • 如果问题仍然存在，请发送电子邮件至 support@gitfocus.app 并提供发生情况的详细信息

要完全重置 GitFocus：

  • 从您的设备中删除应用程序
  • 从 App Store 重新安装
  • 再次完成入门流程

注意：为方便起见，您的 GitHub 用户名或账户列表会被安全存储，因此在重新安装时可能会预填充。
