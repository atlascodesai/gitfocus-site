Направили смо GitFocus са приватношћу као основним принципом. Ево тачно шта радимо (и не радимо) са вашим информацијама.

Подаци које прикупљамо

Никакви. GitFocus не прикупља, не чува нити преноси било какве личне податке на наше сервере јер немамо сервере за њихов пренос.

Све што је апликацији потребно за рад чува се локално на вашем уређају:

  • Ваше GitHub корисничко име или имена (за проверу јавних commit-ова)
  • Ваша подешавања избора апликација
  • Историја ваших сесија фокусирања
  • Подаци о зарађеном времену и серији

Интеграција са GitHub-ом

GitFocus чита јавне GitHub податке о доприносу за додата корисничка имена да би утврдио када сте направили commit-ове. Ево како функционише:

Чему приступамо

  • Ваша јавна GitHub страница профила
  • Ваш јавни график доприноса (зелени квадрати)
  • Број commit-ова по дану (не садржај commit-ова)

Чему не приступамо

  • Приватни репозиторијуми
  • Поруке commit-ова или код
  • Ваша GitHub лозинка или токени
  • Било који GitHub API са аутентификацијом

✅ OAuth није потребан

Намерно смо дизајнирали GitFocus да ради без GitHub аутентификације. Можете додати једно или више GitHub корисничких имена, а ми читамо само јавно доступне информације које свако може видети посетом тих GitHub профила.

Screen Time и блокирање апликација

GitFocus користи Apple-ов Screen Time API (Family Controls framework) за блокирање апликација. Ово је исти сигурни систем који покреће уграђене Screen Time функције од Apple-а.

Како функционише

  • Блокирање апликација у потпуности обрађује iOS, а не наш код
  • Никада не видимо које апликације користите нити колико дуго
  • Apple-ова заштита приватности примењује се на све Screen Time податке
  • Примамо само анонимне "токене" који представљају апликације

Шта не можемо видети

  • Вашу статистику коришћења апликација
  • Када отварате или затварате апликације
  • Колико времена проводите у било којој апликацији
  • Стварна имена изабраних апликација (само токени)

Локално чување података

Сви ваши подаци чувају се на вашем уређају коришћењем Apple-ових сигурних механизама за чување:

  • UserDefaults — Подешавања и преференције
  • Keychain — Ваше примарно GitHub корисничко име (за очување при поновним инсталацијама)
  • App Group — Дељени подаци између апликације и проширења

Ови подаци су шифровани од стране iOS-а и заштићени шифром вашег уређаја. Ако обришете апликацију, ваши локални подаци се такође бришу.

Сервиси трећих страна

GitFocus не користи било какве сервиse трећих страна за аналитику, извештавање о паду или оглашавање. Не интегришемо се са:

  • Google Analytics
  • Firebase
  • Crashlytics
  • Facebook SDK
  • Било којим мрежама за оглашавање
  • Било којим сервисима за праћење корисника

Једини спољни сервиси са којима комуницирамо су github.com за преузимање ваших јавних података о доприносу и наш опциони чет за корисничку подршку (видети доле).

Корисничка подршка и чет

Контактирање подршке је потпуно опционо и дешава се само када одлучите да затражите помоћ.

GitFocus нуди корисничку подршку преко чета који покреће Chatwoot, платформа треће стране за корисничку подршку. Ово је једини сервис треће стране који користи GitFocus (поред GitHub-а), и активан је само када експлицитно одлучите да нас контактирате за помоћ.

Како функционише

  • Очување сесије: Chatwoot користи cookies да одржава вашу чет сесију између посета, тако да можете наставити претходне разговоре
  • Анонимно по подразумеваном: Можете разговарати са подршком без пружања личних информација - сесија се прати само преко cookies прегледача
  • Опциони email: Можете опционо навести вашу адресу е-поште ако желите да примате следеће одговоре

Шта се прикупља

Када користите функцију чета, Chatwoot може прикупљати:

  • Ваше поруке у чету и историју разговора
  • Cookies прегледача за очување сесије
  • Адресу е-поште (само ако одлучите да је наведете)
  • Основне техничке информације (тип прегледача, временска ознака)

✅ Без приступа подацима апликације

Функција чета НЕМА приступ вашим GitHub подацима, историји сесија фокусирања или било којим другим подацима похрањеним у GitFocus апликацији. Само информације које експлицитно укуцате у чет шаљу се нашем систему подршке.

Chatwoot је усклађен са GDPR-ом и обрађује податке у складу са применљивим законима о заштити података. За више информација, посетите chatwoot.com/privacy-policy.

Можете обрисати cookies чета у било ком тренутку преко подешавања прегледача. Ако никада не користите функцију чета, никакви подаци се не шаљу на Chatwoot.

Ваша права

Пошто не прикупљамо ваше податке, традиционална права на податке (приступ, брисање, преносивост) заправо се не примењују. Али ево шта можете урадити:

  • Обрисати све податке — Једноставно обришите апликацију са вашег уређаја
  • Извести податке — Ваши подаци су на вашем уређају; припадају вам
  • Променити подешавања — Све преференције могу се мењати у апликацији

Приватност деце и узрасни рејтинг

GitFocus има рејтинг 4+ у App Store-у и погодан је за кориснике свих узраста. Апликација не садржи неприхватљив садржај, куповине у апликацији или друштвене функције.

Пошто не прикупљамо било какве личне податке, не постоје посебне бриге о приватности за млађе кориснике. Међутим, препоручујемо да деца испод 13 година подесе апликацију уз родитељски надзор, јер:

  • Почетно подешавање захтева GitHub корисничко име
  • Screen Time дозволе морају дати власници уређаја
  • Разумевање система откључавања заснованог на commit-овима може захтевати објашњење

Родитељи и старатељи могу користити GitFocus као алат за подстицање навика програмирања код младих програмера.

Промене у овој политици

Ако икада променимо наше праксе приватности, ажурираћемо ову страницу са новим датумом "Последње ажурирање". С обзиром на наш приступ без прикупљања података, значајне промене су мало вероватне.
