Можете додати више GitHub налога и одлучити који се узимају у обзир за откривање commit-ова.

GitFocus користи Apple-ов Screen Time API за блокирање апликација. Ово је исти сигурни систем који покреће уграђену родитељску контролу од Apple-а. Потребна нам је дозвола да применимо ограничења апликација у ваше име.

Да! GitHub по подразумеваном броји све commit-ове (јавне и приватне) у вашем графику доприноса. Све док су подешавања доприноса постављена да приказују "Приватне доприносе", видећемо их.

Идите на свој GitHub профил → Подешавања доприноса → Означите "Приватни доприноси"

Сваки commit вам доноси 5 минута времена откључавања. Послали 3 commit-а? То је 15 минута за прегледање Twitter-а без кривице.

Животи су хитна откључавања. Када искористите живот, све ваше блокиране апликације се откључавају до поноћи. Почињете са 1 бесплатним животом и можете зарадити више кроз серије:

  • Серија од 14 дана: +1 живот
  • Затим +1 живот сваког месеца док одржавате серију

Треба да завршите брзу поруку, али немате времена откључавања? Можете позајмити до 5 минута. Ово ствара "дуг" који се враћа из ваших будућих зарада од commit-ова.

Пример: Позајмите 3 минута. Ваш следећи commit доноси 5 минута, али 3 иду на отплату дуга, остављајући вам 2 минута.

Банка дисциплине прати време које сте зарадили, али нисте искористили. То је мера ваше самоконтроле. Сваки минут који зарадите, али не потрошите на дистракције, иде у вашу банку.

Изазовите себе: Колико минута можете уштедети до краја године?

Градња серије откључава трајне погодности:

  • 14 дана: +1 додатни живот (затим +1/месечно)
  • 30 дана: Недељна банка времена (неискоришћено време се ресетује недељно уместо дневно)
  • 90 дана: Трајно време (зарађено време никада не истиче)

Ево неколико ствари које треба проверити:

  • Уверите се да је ваше GitHub корисничко име правилно унето
  • Ако користите више налога, проверите да су правилни налози омогућени за откривање commit-ова
  • Проверите да се ваши commit-ови приказују на графику доприноса вашег GitHub профила
  • Ако користите приватне репозиторијуме, уверите се да је "Приватни доприноси" омогућено у GitHub подешавањима
  • Сачекајте неколико минута — график доприноса на GitHub-у може да захтева време за ажурирање

Уверите се да сте:

  • Дали Screen Time дозволе током подешавања
  • Изабрали најмање једну апликацију или категорију за блокирање
  • Покренули сесију фокусирања са главног екрана

Ако се проблеми настављају, покушајте да одете у iOS Подешавања → Screen Time и уверите се да GitFocus има потребне дозволе.

Покушајте ове кораке:

  • Приморајте затварање и поново отворите апликацију
  • Рестартујте ваш уређај
  • Уверите се да сте на најновијој верзији GitFocus-а
  • Ако се проблем настави, пошаљите нам email на support@gitfocus.app са детаљима о ономе што се догодило

Да потпуно ресетујете GitFocus:

  • Обришите апликацију са вашег уређаја
  • Поново инсталирајте из App Store-а
  • Прођите кроз процес упознавања поново

Напомена: Ваше GitHub корисничко име или листа налога су безбедно похрањени ради погодности, тако да могу бити унапред попуњени када поново инсталирате.

Брзо решавање проблема

Приморајте освежавање

Повуците надоле на главном екрану да ручно освежите ваше податке о commit-овима са GitHub-а.

Проверите дозволе

Идите у iOS Подешавања → Screen Time → GitFocus да проверите да ли су дозволе дате.

Проверите GitHub

Посетите github.com/[ваше-корисничко-име] и проверите да ваш график доприноса приказује недавне commit-ове.
