// 개인정보 보호정책

귀하의 데이터는 귀하의 것입니다

GitFocus는 개인정보 보호를 핵심 원칙으로 설계되었습니다. 귀하의 정보로 무엇을 하고 무엇을 하지 않는지 정확히 설명합니다.

최종 업데이트: January 2026

// 요약

저희는 귀하의 데이터를 수집하지 않습니다. 끝.

🚫 계정 불필요
📱 모든 것이 기기 내에서
🔒 추적이나 분석 없음
📡 오프라인 작동

수집하는 데이터

없음. GitFocus는 개인 데이터를 수집, 저장 또는 전송하지 않습니다. 전송할 서버 자체가 없기 때문입니다.

앱의 작동에 필요한 모든 것은 기기에 로컬로 저장됩니다:

  • GitHub 사용자 이름 (공개 커밋 확인용)
  • 앱 선택 설정
  • 집중 세션 기록
  • 획득 시간 및 연속 기록 데이터

GitHub 통합

GitFocus는 추가한 GitHub 사용자 이름의 공개 기여 데이터를 읽어 커밋 여부를 판단합니다. 작동 방식은 다음과 같습니다:

액세스하는 정보

  • 공개 GitHub 프로필 페이지
  • 공개 기여 그래프 (녹색 사각형)
  • 일일 커밋 수 (커밋 내용은 제외)

액세스하지 않는 정보

  • 비공개 저장소
  • 커밋 메시지 또는 코드
  • GitHub 비밀번호 또는 토큰
  • 인증이 필요한 GitHub API

✅ OAuth 불필요

GitFocus는 GitHub 인증 없이 작동하도록 의도적으로 설계되었습니다. 하나 또는 여러 개의 GitHub 사용자 이름을 추가할 수 있으며, 누구나 프로필을 방문하여 볼 수 있는 공개 정보만 읽습니다.

Screen Time 및 앱 차단

GitFocus는 Apple의 Screen Time API (Family Controls 프레임워크)를 사용하여 앱을 차단합니다. 이는 Apple 기본 Screen Time 기능과 동일한 보안 시스템입니다.

작동 방식

  • 앱 차단은 iOS가 전적으로 처리하며, 저희 코드는 관여하지 않습니다
  • 어떤 앱을 얼마나 사용했는지는 절대 알 수 없습니다
  • 모든 Screen Time 데이터에는 Apple의 개인정보 보호가 적용됩니다
  • 앱을 나타내는 익명의 "토큰"만 받습니다

볼 수 없는 정보

  • 앱 사용 통계
  • 앱 시작 또는 종료 시간
  • 각 앱에서 보낸 시간
  • 선택한 앱의 실제 이름 (토큰만)

로컬 데이터 저장

모든 데이터는 Apple의 보안 저장 메커니즘을 사용하여 기기에 저장됩니다:

  • UserDefaults — 설정 및 환경설정
  • Keychain — 주요 GitHub 사용자 이름 (재설치 시 유지용)
  • App Group — 앱과 확장 프로그램 간 공유 데이터

이 데이터는 iOS에 의해 암호화되고 기기 암호로 보호됩니다. 앱을 삭제하면 로컬 데이터도 삭제됩니다.

타사 서비스

GitFocus는 타사 분석, 충돌 보고 또는 광고 서비스를 사용하지 않습니다. 다음과 통합하지 않습니다:

  • Google Analytics
  • Firebase
  • Crashlytics
  • Facebook SDK
  • 모든 광고 네트워크
  • 모든 사용자 추적 서비스

통신하는 유일한 외부 서비스는 공개 기여 데이터를 가져오기 위한 github.com과 선택적인 고객 지원 채팅입니다 (아래 참조).

고객 지원 및 실시간 채팅

지원팀 연락은 전적으로 선택 사항이며, 고객이 도움을 요청할 때만 발생합니다.

GitFocus는 타사 고객 지원 플랫폼인 Chatwoot을 통해 실시간 채팅 지원을 제공합니다. 이는 GitHub를 제외하고 GitFocus가 사용하는 유일한 타사 서비스이며, 명시적으로 지원팀에 연락할 때만 활성화됩니다.

작동 방식

  • 세션 유지: Chatwoot은 쿠키를 사용하여 방문 간 채팅 세션을 유지하므로 이전 대화를 계속할 수 있습니다
  • 기본적으로 익명: 개인 정보를 제공하지 않고도 지원팀과 채팅할 수 있습니다 - 세션은 브라우저 쿠키만으로 추적됩니다
  • 선택적 이메일: 후속 응답을 받고 싶다면 선택적으로 이메일 주소를 제공할 수 있습니다

수집되는 정보

채팅 기능을 사용하면 Chatwoot이 다음을 수집할 수 있습니다:

  • 채팅 메시지 및 대화 기록
  • 세션 유지를 위한 브라우저 쿠키
  • 이메일 주소 (제공한 경우에만)
  • 기본 기술 정보 (브라우저 유형, 타임스탬프)

✅ 앱 데이터 액세스 없음

채팅 기능은 GitHub 데이터, 집중 세션 기록 또는 GitFocus 앱에 저장된 기타 데이터에 액세스할 수 없습니다. 채팅에 명시적으로 입력한 정보만 지원 시스템으로 전송됩니다.

Chatwoot은 GDPR을 준수하며 해당 데이터 보호법에 따라 데이터를 처리합니다. 자세한 내용은 다음을 참조하세요 chatwoot.com/privacy-policy.

브라우저 설정에서 언제든지 채팅 쿠키를 지울 수 있습니다. 채팅 기능을 사용하지 않으면 Chatwoot으로 데이터가 전송되지 않습니다.

귀하의 권리

저희는 귀하의 데이터를 수집하지 않으므로 전통적인 데이터 권리 (액세스, 삭제, 이동성)는 실제로 적용되지 않습니다. 하지만 다음을 수행할 수 있습니다:

  • 모든 데이터 삭제 — 기기에서 앱을 삭제하기만 하면 됩니다
  • 데이터 내보내기 — 데이터는 기기에 있으며 귀하의 소유입니다
  • 설정 변경 — 모든 설정은 앱에서 수정할 수 있습니다

어린이 개인정보 보호 및 연령 등급

GitFocus의 등급은 4+ 이며 모든 연령의 사용자에게 적합합니다. 앱에는 부적절한 콘텐츠, 앱 내 구매 또는 소셜 기능이 포함되어 있지 않습니다.

개인 데이터를 수집하지 않으므로 어린 사용자에 대한 특별한 개인정보 보호 우려는 없습니다. 그러나 13세 미만 어린이는 부모의 지도 하에 앱을 설정하는 것이 좋습니다:

  • 초기 설정에는 GitHub 사용자 이름이 필요합니다
  • Screen Time 권한은 기기 소유자가 부여해야 합니다
  • 커밋 기반 잠금 해제 시스템을 이해하려면 설명이 필요할 수 있습니다

부모와 보호자는 GitFocus를 젊은 개발자의 코딩 습관을 장려하는 도구로 사용할 수 있습니다.

본 정책의 변경

개인정보 보호 관행을 변경하는 경우 이 페이지를 새로운 "최종 업데이트" 날짜로 업데이트합니다. 데이터 비수집 접근 방식을 고려할 때 중대한 변경은 가능성이 낮습니다.
