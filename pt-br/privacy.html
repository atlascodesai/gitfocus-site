// Política de Privacidade

Seus dados continuam sendo seus

Construímos o GitFocus com a privacidade como princípio fundamental. Aqui está exatamente o que fazemos (e não fazemos) com suas informações.

Última atualização: janeiro de 2026

// Resumo

Não coletamos seus dados. Ponto final.

🚫 Sem contas necessárias
📱 Tudo no dispositivo
🔒 Sem rastreamento ou análise
📡 Funciona offline

Dados que Coletamos

Nenhum. O GitFocus não coleta, armazena ou transmite nenhum dado pessoal para nossos servidores porque não temos servidores para enviar.

Tudo que o aplicativo precisa para funcionar é armazenado localmente em seu dispositivo:

  • Seu nome de usuário ou nomes de usuário do GitHub (para verificar commits públicos)
  • Suas preferências de seleção de apps
  • Seu histórico de sessões de foco
  • Seus dados de tempo ganho e sequências

Integração com GitHub

O GitFocus lê dados públicos de contribuição do GitHub para o nome ou nomes de usuário que você adicionar, a fim de determinar quando você fez commits. Veja como funciona:

O Que Acessamos

  • Sua página de perfil público do GitHub
  • Seu gráfico público de contribuições (os quadrados verdes)
  • Contagens de commits por dia (não o conteúdo dos commits)

O Que Não Acessamos

  • Repositórios privados
  • Mensagens de commit ou código
  • Sua senha do GitHub ou tokens
  • Nenhuma API do GitHub com autenticação

✅ OAuth Não Necessário

Projetamos intencionalmente o GitFocus para funcionar sem autenticação do GitHub. Você pode adicionar um ou vários nomes de usuário do GitHub, e apenas lemos informações publicamente disponíveis que qualquer pessoa pode ver ao visitar esses perfis do GitHub.

Tempo de Uso e Bloqueio de Apps

O GitFocus usa a API Screen Time da Apple (framework Family Controls) para bloquear apps. É o mesmo sistema seguro que alimenta os recursos integrados de Tempo de Uso da Apple.

Como Funciona

  • O bloqueio de apps é totalmente gerenciado pelo iOS, não pelo nosso código
  • Nunca vemos quais apps você usa ou por quanto tempo
  • As proteções de privacidade da Apple se aplicam a todos os dados de Tempo de Uso
  • Recebemos apenas "tokens" anonimizados que representam apps

O Que Não Podemos Ver

  • Suas estatísticas de uso de apps
  • Quando você abre ou fecha apps
  • Quanto tempo você passa em cada app
  • Os nomes reais dos apps que você seleciona (apenas tokens)

Armazenamento de Dados Local

Todos os seus dados são armazenados em seu dispositivo usando os mecanismos de armazenamento seguro da Apple:

  • UserDefaults — Configurações e preferências
  • Keychain — Seu nome de usuário principal do GitHub (para persistência entre reinstalações)
  • App Group — Dados compartilhados entre o app e extensões

Esses dados são criptografados pelo iOS e protegidos pela senha do seu dispositivo. Se você excluir o app, seus dados locais também serão excluídos.

Serviços de Terceiros

O GitFocus não usa nenhum serviço de análise, relatório de falhas ou publicidade de terceiros. Não nos integramos com:

  • Google Analytics
  • Firebase
  • Crashlytics
  • Facebook SDK
  • Nenhuma rede de publicidade
  • Nenhum serviço de rastreamento de usuários

Os únicos serviços externos com os quais nos comunicamos são github.com para buscar seus dados públicos de contribuição e nosso chat de suporte ao cliente opcional (veja abaixo).

Suporte ao Cliente e Chat ao Vivo

Entrar em contato com o suporte é totalmente opcional e só acontece quando você escolhe buscar ajuda.

O GitFocus oferece suporte ao cliente por meio de chat ao vivo fornecido pelo Chatwoot, uma plataforma de suporte ao cliente de terceiros. Este é o único serviço de terceiros usado pelo GitFocus (além do GitHub), e só está ativo quando você escolhe explicitamente nos contatar para obter ajuda.

Como funciona

  • Persistência da sessão: O Chatwoot usa cookies para manter sua sessão de chat entre visitas, para que você possa continuar conversas anteriores
  • Anônimo por padrão: Você pode conversar com o suporte sem fornecer nenhuma informação pessoal - a sessão é rastreada apenas por cookies do navegador
  • E-mail opcional: Você pode fornecer opcionalmente seu endereço de e-mail se quiser receber respostas de acompanhamento

O Que é Coletado

Quando você usa o recurso de chat, o Chatwoot pode coletar:

  • Suas mensagens de chat e histórico de conversação
  • Cookies do navegador para persistência da sessão
  • Endereço de e-mail (apenas se você optar por fornecê-lo)
  • Informações técnicas básicas (tipo de navegador, timestamp)

✅ Sem Acesso aos Dados do App

O recurso de chat NÃO tem acesso aos seus dados do GitHub, histórico de sessões de foco ou quaisquer outros dados armazenados no app GitFocus. Apenas as informações que você digita explicitamente no chat são enviadas ao nosso sistema de suporte.

O Chatwoot é compatível com GDPR e processa dados de acordo com as leis aplicáveis de proteção de dados. Para mais informações, visite chatwoot.com/privacy-policy.

Você pode limpar os cookies do chat a qualquer momento através das configurações do seu navegador. Se você nunca usar o recurso de chat, nenhum dado será enviado ao Chatwoot.

Seus Direitos

Como não coletamos seus dados, os direitos tradicionais sobre dados (acesso, exclusão, portabilidade) realmente não se aplicam. Mas veja o que você pode fazer:

  • Excluir todos os dados — Simplesmente exclua o app do seu dispositivo
  • Exportar dados — Seus dados estão no seu dispositivo; eles são seus
  • Alterar configurações — Todas as preferências podem ser modificadas no app

Privacidade Infantil e Classificação Etária

O GitFocus é classificado como 4+ na App Store e é adequado para usuários de todas as idades. O app não contém conteúdo impróprio, compras no app ou recursos sociais.

Como não coletamos nenhum dado pessoal, não há preocupações especiais de privacidade para usuários mais jovens. No entanto, recomendamos que crianças menores de 13 anos configurem o app com orientação dos pais, pois:

  • A configuração inicial requer um nome de usuário do GitHub
  • As permissões de Tempo de Uso precisam ser concedidas pelo proprietário do dispositivo
  • Entender o sistema de desbloqueio baseado em commits pode precisar de explicação

Pais e responsáveis podem usar o GitFocus como ferramenta para incentivar hábitos de programação em jovens desenvolvedores.

Alterações a Esta Política

Se mudarmos nossas práticas de privacidade, atualizaremos esta página com uma nova data de "Última atualização". Dado nosso enfoque de não coleta de dados, mudanças significativas são improváveis.
