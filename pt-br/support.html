Perguntas Frequentes

Não! O GitFocus só precisa do nome ou nomes de usuário do GitHub que você escolher rastrear. Lemos os gráficos públicos de contribuição (os quadrados verdes nos perfis) para detectar commits. Sem OAuth, sem tokens, sem senhas necessárias.

Você pode adicionar várias contas do GitHub e decidir quais contam para a detecção de commits.

O GitFocus usa a API Screen Time da Apple para bloquear apps. É o mesmo sistema seguro que alimenta os controles parentais integrados da Apple. Precisamos de permissão para aplicar restrições de apps em seu nome.

Sim! O GitHub conta todos os commits (públicos e privados) em seu gráfico de contribuições por padrão. Desde que suas configurações de contribuição estejam definidas para mostrar "Contribuições privadas", nós as veremos.

Vá para seu perfil do GitHub → Configurações de contribuição → Marque "Contribuições privadas"

Cada commit ganha 5 minutos de tempo de desbloqueio. Enviar 3 commits? São 15 minutos para rolar o Twitter sem culpa. 🎉

Vidas são desbloqueios de emergência. Quando você usa uma vida, todos os seus apps bloqueados são desbloqueados até meia-noite. Você começa com 1 vida grátis e pode ganhar mais através de sequências:

  • Sequência de 14 dias: +1 vida
  • Depois +1 vida a cada mês que você mantiver a sequência

Precisa terminar uma mensagem rápida mas não tem tempo de desbloqueio? Você pode pegar emprestado até 5 minutos. Isso cria uma "dívida" que é paga com os ganhos de seus futuros commits.

Exemplo: Você pega emprestado 3 minutos. Seu próximo commit ganha 5 minutos, mas 3 vão para pagar a dívida, deixando você com 2 minutos.

O Banco de Disciplina rastreia o tempo que você ganhou mas não usou. É uma medida do seu autocontrole. Cada minuto que você ganha mas não gasta em distrações vai para o seu banco.

Desafie-se: Quantos minutos você pode acumular até o final do ano?

Construir uma sequência desbloqueia vantagens permanentes:

  • 14 dias: +1 vida extra (depois +1/mês)
  • 30 dias: Banco de tempo semanal (tempo não usado reinicia semanalmente em vez de diariamente)
  • 90 dias: Tempo permanente (tempo ganho nunca expira)

Aqui estão algumas coisas para verificar:

  • Certifique-se de que seu nome de usuário do GitHub está digitado corretamente
  • Se você usa várias contas, verifique se as contas certas estão habilitadas para detecção de commits
  • Verifique se seus commits aparecem no gráfico de contribuições do seu perfil do GitHub
  • Se estiver usando repos privados, certifique-se de que "Contribuições privadas" está habilitado nas configurações do GitHub
  • Espere alguns minutos — o gráfico de contribuições do GitHub pode demorar para atualizar

Certifique-se de ter:

  • Concedido permissões de Tempo de Uso durante a configuração
  • Selecionado pelo menos um app ou categoria para bloquear
  • Iniciado uma sessão de foco na tela principal

Se os problemas persistirem, tente ir em Ajustes do iOS → Tempo de Uso e certifique-se de que o GitFocus tem as permissões necessárias.

Tente estes passos:

  • Forçar fechamento e reabrir o app
  • Reiniciar seu dispositivo
  • Certifique-se de estar na versão mais recente do GitFocus
  • Se o problema persistir, envie e-mail para support@gitfocus.app com detalhes sobre o que aconteceu

Para reiniciar completamente o GitFocus:

  • Exclua o app do seu dispositivo
  • Reinstale da App Store
  • Passe pela configuração inicial novamente

Nota: Seu nome de usuário do GitHub ou lista de contas é armazenado com segurança por conveniência, então pode estar pré-preenchido quando você reinstalar.
