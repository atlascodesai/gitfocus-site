Часті питання

Ні! GitFocus потрібні лише імена користувачів GitHub, які ви обираєте для відстеження. Ми читаємо публічні графіки внеску (зелені квадрати в профілях) для виявлення комітів. Не потрібно OAuth, токенів або паролів.

Ви можете додати кілька акаунтів GitHub і вирішити, які з них враховуються при виявленні комітів.

GitFocus використовує API Screen Time від Apple для блокування додатків. Це та сама безпечна система, яка забезпечує вбудований батьківський контроль Apple. Нам потрібен дозвіл для застосування обмежень додатків від вашого імені.

Так! GitHub за замовчуванням враховує всі коміти (публічні та приватні) у вашому графіку внеску. Поки ваші налаштування внеску встановлені на відображення "Приватних внесків", ми їх побачимо.

Перейдіть до свого профілю GitHub → Налаштування внеску → Позначте "Приватні внески"

Кожен коміт дає вам 5 хвилин часу розблокування. Зробили 3 коміти? Це 15 хвилин для перегляду Twitter без докорів сумління. 🎉

Життя — це екстрені розблокування. Коли ви використовуєте життя, всі ваші заблоковані додатки розблокуються до півночі. Ви починаєте з 1 безкоштовного життя і можете заробити більше через серії:

  • Серія у 14 днів: +1 життя
  • Потім +1 життя кожен місяць, поки ви підтримуєте серію

Потрібно швидко закінчити повідомлення, але немає часу розблокування? Ви можете позичити до 5 хвилин. Це створює "борг", який виплачується з ваших майбутніх заробітків від комітів.

Приклад: Ви позичили 3 хвилини. Ваш наступний коміт приносить 5 хвилин, але 3 йдуть на погашення боргу, залишаючи вам 2 хвилини.

Банк дисципліни відстежує час, який ви заробили, але не використали. Це міра вашого самоконтролю. Кожна хвилина, яку ви заробляєте, але не витрачаєте на відволікання, йде до вашого банку.

Кинь собі виклик: Скільки хвилин ти зможеш накопичити до кінця року?

Побудова серії розблокує постійні переваги:

  • 14 днів: +1 додаткове життя (потім +1/місяць)
  • 30 днів: Щотижневий банк часу (невикористаний час скидається щотижня замість щодня)
  • 90 днів: Постійний час (зароблений час ніколи не закінчується)

Ось що потрібно перевірити:

  • Переконайтеся, що ваше ім'я користувача GitHub введено правильно
  • Якщо ви використовуєте кілька акаунтів, перевірте, що правильні акаунти включені для виявлення комітів
  • Перевірте, що ваші коміти відображаються в графіку внеску вашого профілю GitHub
  • Якщо використовуються приватні репозиторії, переконайтеся, що "Приватні внески" увімкнені в налаштуваннях GitHub
  • Зачекайте кілька хвилин — графік внеску GitHub може оновлюватися із затримкою

Переконайтеся, що ви:

  • Надали дозволи Screen Time під час налаштування
  • Обрали принаймні один додаток або категорію для блокування
  • Почали сеанс фокусування з головного екрана

Якщо проблеми зберігаються, спробуйте перейти до Налаштувань iOS → Screen Time і переконайтеся, що GitFocus має необхідні дозволи.

Спробуйте ці кроки:

  • Примусово закрийте і відкрийте додаток знову
  • Перезавантажте пристрій
  • Переконайтеся, що у вас встановлена остання версія GitFocus
  • Якщо проблема зберігається, напишіть нам на support@gitfocus.app з деталями про те, що сталося

Для повного скидання GitFocus:

  • Видаліть додаток зі свого пристрою
  • Перевстановіть з App Store
  • Пройдіть процес адаптації знову

Примітка: Ваше ім'я користувача GitHub або список акаунтів зберігається безпечно для зручності, тому вони можуть бути попередньо заповнені при перевстановленні.
