Які дані ми збираємо

Жодних. GitFocus не збирає, не зберігає і не передає жодні персональні дані на наші сервери, тому що у нас немає серверів для їх передачі.

Все, що потрібно додатку для роботи, зберігається локально на вашому пристрої:

  • Ваше ім'я користувача GitHub або імена (для перевірки публічних комітів)
  • Ваші вподобання вибору додатків
  • Історія ваших сеансів фокусування
  • Дані про зароблений час та серії

Інтеграція з GitHub

GitFocus читає публічні дані про внесок GitHub для доданих імен користувачів, щоб визначити, коли ви робите коміти. Ось як це працює:

До чого ми отримуємо доступ

  • Ваша публічна сторінка профілю GitHub
  • Ваш публічний графік внеску (зелені квадрати)
  • Кількість комітів за день (не вміст комітів)

До чого ми не отримуємо доступ

  • Приватні репозиторії
  • Повідомлення комітів або код
  • Ваш пароль або токени GitHub
  • Будь-який GitHub API з аутентифікацією

OAuth не потрібен

Ми навмисно спроектували GitFocus так, щоб працювати без аутентифікації GitHub. Ви можете додати одне або декілька імен користувачів GitHub, і ми читаємо лише публічно доступну інформацію, яку будь-хто може побачити, відвідавши ці профілі GitHub.

Screen Time та блокування додатків

GitFocus використовує API Screen Time від Apple (фреймворк Family Controls) для блокування додатків. Це та сама безпечна система, яка забезпечує вбудовані функції Screen Time від Apple.

Як це працює

  • Блокування додатків повністю обробляється iOS, а не нашим кодом
  • Ми ніколи не бачимо, які додатки ви використовуєте і скільки часу
  • Захист конфіденційності Apple застосовується до всіх даних Screen Time
  • Ми отримуємо лише анонімні "токени", які представляють додатки

Що ми не можемо бачити

  • Вашу статистику використання додатків
  • Коли ви відкриваєте або закриваєте додатки
  • Скільки часу ви проводите в будь-якому додатку
  • Фактичні назви обраних вами додатків (лише токени)

Локальне зберігання даних

Всі ваші дані зберігаються на вашому пристрої з використанням безпечних механізмів зберігання Apple:

  • UserDefaults — Налаштування та вподобання
  • Keychain — Ваше основне ім'я користувача GitHub (для збереження при перевстановленнях)
  • App Group — Спільні дані між додатком та розширеннями

Ці дані шифруються iOS і захищаються кодом доступу вашого пристрою. Якщо ви видалите додаток, ваші локальні дані також будуть видалені.

Сторонні сервіси

GitFocus не використовує будь-які сторонні сервіси аналітики, звітів про збої або реклами. Ми не інтегруємося з:

  • Google Analytics
  • Firebase
  • Crashlytics
  • Facebook SDK
  • Будь-якими рекламними мережами
  • Будь-якими сервісами відстеження користувачів

Єдині зовнішні сервіси, з якими ми взаємодіємо, це github.com для отримання ваших публічних даних про внесок та наш опціональний чат підтримки клієнтів (див. нижче).

Підтримка клієнтів та чат

Звернення до служби підтримки повністю опціональне і відбувається лише тоді, коли ви вирішите звернутися за допомогою.

GitFocus пропонує підтримку клієнтів через онлайн-чат на базі Chatwoot, сторонньої платформи підтримки клієнтів. Це єдиний сторонній сервіс, який використовується GitFocus (окрім GitHub), і він активний лише тоді, коли ви явно вирішуєте звернутися до нас за допомогою.

Як це працює

  • Збереження сеансу: Chatwoot використовує cookies для підтримки вашого сеансу чату між відвідуваннями, щоб ви могли продовжити попередні розмови
  • Анонімно за замовчуванням: Ви можете спілкуватися зі службою підтримки без надання особистої інформації - сеанс відстежується лише через cookies браузера
  • Опціональний email: Ви можете додатково вказати свою адресу електронної пошти, якщо хочете отримувати наступні відповіді

Що збирається

Коли ви використовуєте функцію чату, Chatwoot може збирати:

  • Ваші повідомлення в чаті та історію розмови
  • Cookies браузера для збереження сеансу
  • Адресу електронної пошти (лише якщо ви вирішите її вказати)
  • Базову технічну інформацію (тип браузера, мітка часу)

Немає доступу до даних додатка

Функція чату НЕ має доступу до ваших даних GitHub, історії сеансів фокусування або будь-яких інших даних, що зберігаються в додатку GitFocus. Лише інформація, яку ви явно вводите в чат, надсилається до нашої системи підтримки.

Chatwoot відповідає GDPR і обробляє дані відповідно до застосовних законів про захист даних. Для отримання додаткової інформації відвідайте chatwoot.com/privacy-policy.

Ви можете очистити cookies чату в будь-який час через налаштування браузера. Якщо ви ніколи не використовуєте функцію чату, жодні дані не надсилаються до Chatwoot.

Ваші права

Оскільки ми не збираємо ваші дані, традиційні права на дані (доступ, видалення, переносимість) насправді не застосовуються. Але ось що ви можете зробити:

  • Видалити всі дані — Просто видаліть додаток зі свого пристрою
  • Експортувати дані — Ваші дані знаходяться на вашому пристрої; вони належать вам
  • Змінити налаштування — Всі вподобання можна змінити в додатку

Конфіденційність дітей та віковий рейтинг

GitFocus має рейтинг 4+ в App Store і підходить для користувачів усіх віків. Додаток не містить небажаного контенту, вбудованих покупок або соціальних функцій.

Оскільки ми не збираємо жодні персональні дані, для молодших користувачів немає особливих проблем з конфіденційністю. Однак ми рекомендуємо, щоб діти до 13 років налаштовували додаток під керівництвом батьків, оскільки:

  • Початкове налаштування вимагає імені користувача GitHub
  • Дозволи Screen Time повинні бути надані власником пристрою
  • Розуміння системи розблокування на основі комітів може потребувати пояснення

Батьки та опікуни можуть використовувати GitFocus як інструмент для заохочення звичок програмування у юних розробників.

Зміни в цій політиці
