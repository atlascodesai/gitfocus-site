// プライバシーポリシー

あなたのデータはあなたのものです

GitFocusはプライバシーを最優先に設計されています。あなたの情報をどのように扱い、また扱わないかをご説明します。

最終更新日: January 2026

// 要約

私たちはあなたのデータを一切収集しません。以上です。

🚫 アカウント不要
📱 すべてデバイス上で完結
🔒 トラッキングや分析なし
📡 オフラインで動作

収集するデータ

なし。 GitFocusは個人データを一切収集、保存、送信しません。そもそも送信先となるサーバーを持っていないためです。

アプリの動作に必要なすべてのデータは、お使いのデバイスにローカルに保存されます:

  • GitHubユーザー名（公開コミットの確認のため）
  • アプリ選択設定
  • 集中セッション履歴
  • 獲得時間とストリークデータ

GitHub連携

GitFocusは、追加されたGitHubユーザー名の公開コントリビューションデータを読み取り、コミットの有無を判定します。その仕組みは以下の通りです:

アクセスする情報

  • 公開GitHubプロフィールページ
  • 公開コントリビューショングラフ（緑の四角）
  • 1日あたりのコミット数（コミット内容は含まない）

アクセスしない情報

  • プライベートリポジトリ
  • コミットメッセージやコード
  • GitHubパスワードやトークン
  • 認証が必要なGitHub API

✅ OAuth不要

GitFocusはGitHub認証なしで動作するよう意図的に設計されています。1つまたは複数のGitHubユーザー名を追加でき、誰でもプロフィールにアクセスして閲覧できる公開情報のみを読み取ります。

Screen Timeとアプリブロック

GitFocusはAppleのScreen Time API（Family Controlsフレームワーク）を使用してアプリをブロックします。これはApple標準のScreen Time機能と同じセキュアなシステムです。

仕組み

  • アプリのブロックはiOSが完全に処理し、私たちのコードは関与しません
  • どのアプリをどれだけ使用したかは一切把握しません
  • Screen Timeデータにはすべて、Appleのプライバシー保護が適用されます
  • アプリを表す匿名の「トークン」のみを受け取ります

見えない情報

  • アプリ使用統計
  • アプリの起動・終了時刻
  • 各アプリの使用時間
  • 選択したアプリの実際の名前（トークンのみ）

ローカルデータ保存

すべてのデータは、Appleのセキュアなストレージ機構を使用してデバイスに保存されます:

  • UserDefaults — 設定と環境設定
  • Keychain — 主要GitHubユーザー名（再インストール時の保持のため）
  • App Group — アプリと拡張機能間の共有データ

このデータはiOSにより暗号化され、デバイスのパスコードで保護されます。アプリを削除すると、ローカルデータも削除されます。

サードパーティサービス

GitFocusは、サードパーティの分析、クラッシュレポート、広告サービスを一切使用しません。以下との連携もありません:

  • Google Analytics
  • Firebase
  • Crashlytics
  • Facebook SDK
  • 広告ネットワーク全般
  • ユーザートラッキングサービス全般

通信する外部サービスは、公開コントリビューションデータを取得するためのgithub.comと、オプションのカスタマーサポートチャット（後述）のみです。

カスタマーサポートとライブチャット

サポートへの連絡は完全に任意であり、お客様がサポートを求めた場合にのみ発生します。

GitFocusは、サードパーティのカスタマーサポートプラットフォームであるChatwootを利用したライブチャットサポートを提供しています。これはGitHubを除き、GitFocusが使用する唯一のサードパーティサービスであり、お客様が明示的にサポートに連絡した場合にのみ有効になります。

仕組み

  • セッションの永続化: Chatwootはクッキーを使用してチャットセッションを保持し、前回の会話を継続できるようにします
  • デフォルトで匿名: 個人情報を提供せずにサポートとチャットできます - セッションはブラウザのクッキーのみで追跡されます
  • 任意のメールアドレス: フォローアップの返信を受け取りたい場合は、任意でメールアドレスを提供できます

収集される情報

チャット機能を使用すると、Chatwootは以下を収集する場合があります:

  • チャットメッセージと会話履歴
  • セッション保持のためのブラウザクッキー
  • メールアドレス（提供した場合のみ）
  • 基本的な技術情報（ブラウザの種類、タイムスタンプ）

✅ アプリデータへのアクセスなし

チャット機能は、GitHubデータ、集中セッション履歴、その他GitFocusアプリに保存されているデータにアクセスできません。チャットに明示的に入力した情報のみがサポートシステムに送信されます。

ChatwootはGDPRに準拠しており、適用されるデータ保護法に従ってデータを処理します。詳細については、以下をご覧ください chatwoot.com/privacy-policy.

ブラウザの設定からいつでもチャットクッキーをクリアできます。チャット機能を一度も使用しない場合、Chatwootにデータが送信されることはありません。

お客様の権利

私たちはお客様のデータを収集しないため、従来のデータ権（アクセス、削除、移植性）は実質的に適用されません。しかし、以下のことが可能です:

  • すべてのデータを削除 — デバイスからアプリを削除するだけです
  • データのエクスポート — データはデバイスに保存されており、お客様のものです
  • 設定の変更 — すべての設定はアプリ内で変更できます

子どものプライバシーと年齢制限

GitFocusのレーティングは 4+ であり、すべての年齢のユーザーに適しています。アプリには不適切なコンテンツ、アプリ内課金、ソーシャル機能は含まれていません。

個人データを一切収集しないため、若年ユーザーに特別なプライバシー上の懸念はありません。ただし、13歳未満のお子様には保護者の監督のもとでアプリを設定することをお勧めします:

  • 初期設定にはGitHubユーザー名が必要です
  • Screen Timeの許可はデバイス所有者が付与する必要があります
  • コミットベースのロック解除システムの理解には説明が必要な場合があります

保護者はGitFocusを若い開発者のコーディング習慣を奨励するツールとして利用できます。

本ポリシーの変更

プライバシー慣行を変更する場合は、このページを新しい「最終更新日」とともに更新します。データ非収集のアプローチを考えると、大幅な変更は想定されていません。
